GPU Compute Index

What it costs to rent one AI GPU for one hour, in US dollars. One number per GPU model per day, built from public AWS and Azure list prices by written rules, from a tamper-evident ledger anyone can verify.

Methodology
—
git clone https://github.com/julionmalek/gpu-compute-index
cd gpu-compute-index
PYTHONPATH=src python3 -m gpu_index verify   # checks every hash in the chain
PYTHONPATH=src python3 -m gpu_index build    # recomputes index/ byte for byte
git diff --exit-code index/                  # no output = the published numbers check out

Python 3.11+, standard library only. Raw prices live in ledger/, one file per day.

Built by Julion Malek. List prices, not traded prices: actual deals are usually cheaper.
